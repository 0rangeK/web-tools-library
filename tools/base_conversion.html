进制转换

在任意一行输入数值，其余三行会自动同步转换为对应的进制。所有计算都在本地浏览器中完成，不会上传任何数据。

使用说明

  • 支持 2、8、10、16 进制整数之间的相互转换，修改任意一行即可。
  • 十六进制不区分大小写，输出的字母统一为小写。
  • 支持正负号，例如 -1010 表示负的二进制数。
  • 可粘贴带前缀的写法，前缀会被自动识别并忽略：0b1010（二进制）、0o755（八进制）、0xFF（十六进制）。
  • 输入中的空格与下划线会被忽略，例如 1010 1010 等价于 10101010。
  • 不支持小数、分数、科学计数法（如 1e3）以及 3 进制等其它进制。
  • 内部使用 BigInt 精确计算，不会出现浮点精度丢失；单行最多 1024 个字符。
  • 「复制」按钮优先使用系统剪贴板 API；在本地 file:// 打开时若该 API 被限制，会自动降级为 document.execCommand 方式。
