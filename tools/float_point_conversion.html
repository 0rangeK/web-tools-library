浮点数进制转换

输入十进制浮点数，或直接编辑任意一行的二进制 / 十六进制值，其余各行会自动同步转换。 计算遵循 IEEE 754 标准，全部在浏览器本地完成。

输入的浮点数
Float 单精度 32 bit
Double 双精度 64 bit

说明

  • IEEE 754 位布局：单精度 32 位 = 1 位符号 + 8 位阶码 + 23 位尾数； 双精度 64 位 = 1 位符号 + 11 位阶码 + 52 位尾数。
  • 二进制输入不足位数时自动在左侧补 0；十六进制输入可省略 0x 前缀，大小写不限。
  • 十进制显示采用「能唯一还原该数值的最短十进制串」。因此 32 位与 64 位的 0.1 十进制显示可能相同，但它们的二进制 / 十六进制位模式不同（这正是精度差异的体现）。
  • 最上方「输入的浮点数」与 double 十进制行在数值上等价，属于设计上的对照冗余。
  • 不支持 NaN 与 Infinity 之间的互相转换：若输入的十进制数值超出 float 单精度范围， 单精度部分会显示为 Infinity；若输入的位模式表示 Infinity / NaN，则会给出错误提示。
  • 全部运算在本地浏览器完成，不联网、不上传任何数据。
  • 复制优先调用 Clipboard API；若浏览器在 file:// 环境下限制该接口， 会自动回退到 document.execCommand('copy')。两者均被拒绝时请手动选中后按 Ctrl+C。
